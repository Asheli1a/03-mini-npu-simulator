# AI 발전사로 이해하는 MAC의 중요성

전문가 시스템에서 SVM, CNN, 트랜스포머로 이어지는 변화를 통해 MAC이 현대 AI의 핵심 계산이 된 이유와 Mini NPU Simulator의 학습 범위를 정리한다.

## 1. 핵심 개념: 중요도를 곱해 합산한다

MAC(Multiply-Accumulate)은 입력과 가중치를 곱한 값을 누적하는 계산이다.

```python
score += input_value * weight
```

여러 입력을 처리하면 `점수 = x₁w₁ + x₂w₂ + … + xₙwₙ` 형태의 가중합이 된다. 곱셈은 각 입력의 기여도를 조절하고, 덧셈은 여러 입력의 기여를 하나로 모은다. 신경망의 선형 계층과 합성곱은 이러한 계산을 대규모로 수행한다. 여러 가중합을 묶으면 행렬곱으로 표현할 수 있다. [NVIDIA 행렬곱 설명](https://docs.nvidia.com/deeplearning/performance/dl-performance-matrix-multiplication/index.html)

예를 들어 고양이 판별 장치에서 뾰족한 귀와 수염에는 양의 가중치를, 긴 주둥이에는 음의 가중치를 줄 수 있다. 각 관찰값에 가중치를 곱해 더하면 여러 단서를 종합한 점수가 된다. 이는 가중합을 설명하기 위한 비유이며, 실제 신경망의 개별 숫자에 항상 ‘귀’나 ‘수염’ 같은 뜻이 대응한다는 의미는 아니다.

AI 발전을 이해하는 질문은 ‘무엇을 보고 판단할지, 각각을 얼마나 중요하게 볼지, 서로 어떤 관계로 볼지를 누가 결정하는가’이다.

## 2. 발전사 개요

| 접근 | 판단 방식의 중심 | 사람이 주로 설계하는 것 | MAC과의 관계 |
|---|---|---|---|
| 전문가 시스템 | 명시적 지식과 규칙 적용 | 지식·조건·추론 규칙 | 대규모 가중합이 대표적인 중심 구조는 아님 |
| 전통적 특징 추출 + SVM | 특징 공간에서 분류 경계 학습 | 특징 추출 방법과 학습 설정 | 내적·가중합·커널 계산에 사용 |
| CNN | 시각적 특징과 분류 기준을 함께 학습 | 층 구성·학습 설정 | 합성곱과 완전연결층에서 대량 반복 |
| 트랜스포머 | 문맥에 따른 관계와 표현을 학습 | 모델 구조·학습 설정 | 어텐션과 피드포워드층에서 대규모 행렬 연산 |

이 표는 주요 접근의 차이를 비교한 것이며, 앞선 방식이 사라지고 다음 방식으로 완전히 교체됐다는 뜻은 아니다. SVM도 기계학습이며, CNN과 트랜스포머는 기계학습에 포함되는 신경망 계열이다. 모든 기계학습이 MAC 중심인 것도 아니다. [기계학습 개요](https://www.ibm.com/think/topics/machine-learning), [SVM 설명](https://scikit-learn.org/stable/modules/svm.html), [AlexNet과 특징 학습](https://classic.d2l.ai/chapter_convolutional-modern/alexnet.html), [셀프 어텐션 설명](https://www.ibm.com/think/topics/self-attention)

## 3. 전문가 시스템: 판단 규칙을 사람이 작성한다

전문가 시스템은 사람이 정리한 지식과 추론 규칙을 적용하는 접근이다. 다음은 그 방식을 보여주는 가상의 규칙이다.

```text
귀가 뾰족하고, 수염이 있고, 주둥이가 짧다면
→ 고양이로 판단한다.
```

이 방식에서는 어떤 특징을 조건으로 삼을지와 어떤 조건 조합을 결론으로 연결할지를 사람이 정한다. 따라서 시스템의 작동 원리를 이해할 때도 대규모 행렬곱보다는 규칙의 적용과 추론을 먼저 생각하는 편이 적절하다. 숫자 계산이 전혀 없다는 의미는 아니다. 데이터에서 패턴을 학습하는 기계학습과의 차이는 판단 지식을 확보하는 방식에 있다. [기계학습과 규칙 기반 접근의 차이](https://www.ibm.com/think/topics/machine-learning)

## 4. SVM: 구분하는 경계를 데이터에서 배운다

전통적인 영상 인식에서는 사람이 설계한 방법으로 윤곽·질감 등의 특징을 추출한 뒤 분류기에 넣는 구성이 널리 쓰였다. SVM은 이렇게 주어진 특징에서 두 부류를 구분하는 경계를 학습하는 대표적인 방법이다. 직관적으로는 고양이 데이터와 개 데이터 사이에 양쪽과의 여유 공간이 큰 경계를 놓는 것이다. [SVM 설명](https://scikit-learn.org/stable/modules/svm.html), [딥러닝 이전의 영상 인식과 특징 설계](https://classic.d2l.ai/chapter_convolutional-modern/alexnet.html)

```text
이미지 → 사람이 설계한 특징 추출 → SVM의 분류 경계 → 판단
```

선형 SVM의 판단 점수는 `점수 = Σ xᵢwᵢ + b` 형태다. 입력 특징과 학습한 가중치의 곱을 더하므로 여기에도 MAC이 사용된다. 비선형 SVM은 커널을 이용해 더 복잡한 경계를 표현한다. 커널의 종류에 따라 필요한 계산은 달라지므로, 모든 SVM 계산을 단순한 선형 가중합 하나로 설명할 수는 없다. [SVM의 수학적 정의와 커널](https://scikit-learn.org/stable/modules/svm.html)

따라서 CNN 이후에 곱셈과 덧셈이 처음 등장한 것은 아니다. 중요한 변화는 특징을 어디까지 학습하고, 그 계산을 얼마나 깊고 크게 반복하느냐에 있다.

## 5. CNN: 무엇을 볼 것인지까지 학습한다

CNN(합성곱 신경망)은 이미지에서 유용한 특징을 추출하는 필터까지 학습한다. 전통적 특징 추출과 분류를 분리한 방식에 비해, 특징 추출과 최종 판단을 함께 학습할 수 있다는 점이 중요하다. 2012년 AlexNet은 이러한 학습된 특징과 GPU 활용의 효과를 보여준 대표적인 사례다. [AlexNet 설명](https://classic.d2l.ai/chapter_convolutional-modern/alexnet.html)

합성곱은 작은 필터를 이미지의 여러 위치에 적용하며 입력과 필터의 같은 위치 값을 곱해 더하는 계산이다.

```text
작은 영역의 입력 × 필터 가중치 → 합산 → 해당 위치의 출력
                                ↓
                     다른 위치와 필터에도 반복
```

입력 채널이 하나인 3×3 필터는 출력 한 지점당 9 MAC이 필요하다. 입력 채널이 64개라면 `3 × 3 × 64 = 576 MAC`이다. 편향 덧셈과 활성화 연산 등은 이 MAC 수에 포함하지 않았다. 같은 계산을 여러 위치·출력 채널·층에서 반복하면서 전체 계산량이 커진다. [신경망 행렬 연산과 합성곱의 계산 구조](https://docs.nvidia.com/deeplearning/performance/dl-performance-matrix-multiplication/index.html)

여러 위치와 필터의 계산을 병렬 처리하고 행렬 연산으로 묶을 수 있다는 점이 GPU와 잘 맞는다. 더 좋은 특징을 배우기 위한 대규모 계산을 하드웨어가 감당할 수 있게 된 것이다. AlexNet은 두 대의 GTX 580을 사용했다. [AlexNet의 GPU 활용](https://classic.d2l.ai/chapter_convolutional-modern/alexnet.html)

## 6. 트랜스포머: 입력에 따라 참고할 관계를 계산한다

CNN의 전형적인 합성곱은 학습된 필터를 여러 위치에 적용한다. 반면 트랜스포머의 셀프 어텐션은 현재 입력에 따라 토큰들이 서로를 얼마나 참고할지 계산한다. 토큰은 모델이 처리하는 글자·단어 조각 등의 단위다. [셀프 어텐션 설명](https://www.ibm.com/think/topics/self-attention)

예를 들어 ‘철수가 영희에게 우산을 빌려줬다’라는 문장을 처리할 때, 각 토큰을 고립해서 보지 않고 다른 토큰의 정보를 참고해 표현을 바꾼다. 어텐션은 이 참고 비중을 계산하는 장치다. 사람이 문장을 이해하는 과정을 그대로 구현했거나, 지시 대상을 항상 정확하게 판단한다는 뜻은 아니다.

어텐션의 주요 흐름은 다음과 같다.

1. 입력의 숫자 표현을 변환해 Q(질문), K(비교 단서), V(전달할 정보)를 만든다.
2. Q와 K의 내적으로 관련성 점수를 계산한다.
3. 점수를 조정하고 softmax로 참고 비중을 만든다.
4. 참고 비중을 V에 곱해 합산한다.

관계 점수를 구하는 내적과 정보를 섞는 가중합에는 MAC이 반복된다. 여러 토큰을 묶으면 행렬곱으로 처리할 수 있다. [셀프 어텐션의 Q·K·V와 계산 과정](https://www.ibm.com/think/topics/self-attention)

트랜스포머에는 어텐션 외에도 각 토큰의 표현을 변환하는 피드포워드 신경망이 있다. 이 부분 역시 행렬곱을 주요 계산으로 사용한다. 따라서 트랜스포머의 계산량을 어텐션 하나만으로 이해해서는 안 된다. [트랜스포머 구조와 피드포워드 계층](https://arxiv.org/abs/1706.03762), [신경망의 행렬곱](https://docs.nvidia.com/deeplearning/performance/dl-performance-matrix-multiplication/index.html)

## 7. Mini NPU Simulator와 연결하기

이번 프로젝트의 핵심 계산은 다음과 같다.

```python
score += pattern[row][column] * filter_matrix[row][column]
```

같은 위치의 패턴 값과 필터 값을 곱해 더한다. 두 배열을 같은 순서로 펼치면 길이 N²인 두 벡터의 내적이다. 필터 하나의 점수는 N² MAC이며, 두 필터의 점수를 구하면 2N² MAC이다. 계산하는 모든 원소를 순회하므로 한 변의 길이 N에 대한 시간 복잡도는 O(N²)이다.

이 계산은 CNN의 한 영역과 필터 사이에서 일어나는 가중합의 기초와 연결된다. 다만 현재 프로그램은 필터를 이미지 위로 이동시켜 특징 지도를 만드는 전체 합성곱 계층이 아니라, 같은 크기의 패턴과 필터를 비교해 점수 하나를 계산하는 구현이다.

| 이번 구현에서 다루는 것 | 이번 구현에서 다루지 않는 것 |
|---|---|
| 입력과 필터의 곱셈·누산 | 데이터로 필터 가중치를 학습하는 과정 |
| 두 필터의 점수 비교와 동점 처리 | 손실 함수·역전파·최적화 |
| 배열 크기에 따른 계산량과 실행 시간 | 다층 CNN·트랜스포머 전체 구조 |
| 2차원과 1차원 구현의 동등성·비용 비교 | 실제 GPU·Tensor Core·NPU의 실행 성능 |

현재 프로그램의 필터는 입력·JSON·생성 규칙으로 주어지며, 학습으로 갱신되지 않는다. 따라서 학습하는 신경망 전체를 구현한 것은 아니다. Python CPU 반복문으로 MAC의 원리와 계산 비용을 관찰하는 학습용 시뮬레이터로 이해한다. 구현·검증·측정 기록은 [README](../README.md)에 정리했다.

1차원 평탄화도 점수식을 바꾸는 작업이 아니다. 원소 처리 순서가 같다면 같은 계산을 다른 자료 접근 방식으로 수행한다. 평탄화가 자동으로 행렬곱 전용 하드웨어 사용을 뜻하거나, 필터의 분류 한계를 해소하는 것은 아니다.

## 8. MAC 수와 AI 성능을 혼동하지 않기

MAC은 지능의 설계도가 아니라 여러 모델이 공통으로 사용하는 계산 재료다. 같은 곱셈과 덧셈을 사용해도 SVM의 분류 경계, CNN의 특징 추출, 트랜스포머의 어텐션은 구조와 역할이 다르다. MAC 수가 많다는 이유만으로 더 정확하거나 더 지능적이라고 결론 내릴 수 없다.

또한 신경망에는 활성화·정규화·softmax 등 다른 연산도 필요하다. MAC만 빠르게 계산한다고 전체 실행 시간이 같은 비율로 줄어드는 것도 아니다. 행렬곱 자체도 데이터 이동과 연산량의 관계에 따라 성능 제한 요인이 달라진다. [셀프 어텐션의 softmax](https://www.ibm.com/think/topics/self-attention), [행렬곱의 메모리·연산 병목](https://docs.nvidia.com/deeplearning/performance/dl-performance-matrix-multiplication/index.html)

연산량 표기에서도 단위를 구분한다. 통상 부동소수점 연산을 셀 때 1 MAC은 곱셈 1회와 덧셈 1회, 즉 2 FLOPs로 계산한다. 이 프로젝트의 25×25 필터 하나는 625 MAC이며, 곱셈·누적 덧셈을 따로 세면 1,250회다. 이는 Python 코드가 단일 반올림의 하드웨어 FMA 명령으로 실행된다는 뜻이 아니다. [행렬곱 연산량 표기](https://docs.nvidia.com/deeplearning/performance/dl-performance-matrix-multiplication/index.html)

## 9. 내 말로 설명하기

> 전문가 시스템은 사람이 작성한 규칙을 적용하고, 기계학습은 데이터에서 판단 기준을 배운다. CNN은 유용한 특징을 추출하는 필터까지 학습하고, 트랜스포머는 문맥에 따라 어떤 정보를 참고할지도 계산한다. 이 과정에서 입력에 가중치를 곱해 더하는 계산이 대규모로 반복되므로 MAC과 행렬곱을 빠르게 실행하는 하드웨어가 중요해졌다. 이번 Mini NPU Simulator는 그 기초인 패턴과 필터의 곱셈·누산을 직접 구현한 프로그램이다.

하드웨어별 실행 방식과 비교 조건은 [MAC과 하드웨어 가속: CPU SIMD·Pascal CUDA·Tensor Core·NPU 비교](mac-hardware-acceleration.md)에서 이어서 다룬다. 해당 문서는 기존 프로젝트 파일을 가리키며, 이번 설명 문서 추가로 프로그램의 실행 방식이나 기존 검증 결과가 바뀌지는 않는다.
