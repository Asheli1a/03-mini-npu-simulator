## 강의 예시와 달라도 유지한 설계

- src/와 강의의 함수명을 그대로 만들 필요는 없다. 현재 함수별 검증·계산·판정·출력 책임을 유지하며 제출 직전에 대규모 모듈 재편을 하지 않는다.
- read_matrix()는 오류가 난 행만 다시 받는다. 강의의 배열 전체 재입력은 예시이며, 안내 후 재입력이라는 필수 요구를 만족한다.
- normalize_label()은 알 수 없는 값에 None 대신 ValueError를 발생시키고 analyze_data()가 케이스 FAIL로 변환한다. 강의의 plus·ex는 예시 별칭이므로 추가하지 않았다.
- score의 5.0과 강의의 5는 숫자 표시 차이다. 입력과 계산은 기존 float 경로를 유지한다.
- perf_counter_ns()는 차이를 ms로 환산한다. 1,000회는 미션의 최소 10회 이상을 충족하며 타이머·함수 호출 비용을 숨기지 않는다. 강의의 절대 시간 수치를 프로젝트 측정값으로 옮기지 않았다.
- 해결 가이드의 동점 3건은 현재 결과와 일치한다. 수치 비교라는 분류는 tie에 대응하며, numeric(오버플로 등)과 다르다. 강의의 로직 분류를 따라 prediction_mismatch만으로 코드 버그라고 단정하지 않는다.
- CPU/GPU/NPU 비교의 입문용 단순화는 그대로 일반화하지 않는다. CPU의 SIMD·멀티코어와 실제 가속기의 데이터 이동·정밀도·호출 비용을 구분하는 기존 심화 설명을 유지한다.
- 1e-9가 모든 규모에서 오차와 실제 점수 차이를 구분한다는 보편적 보장은 하지 않는다. 과제의 절대오차 정책을 유지하고 상대오차는 향후 검토로 남긴다.

## 실행 검증과 한계

AI 보조 도구 Perplexity의 Python 3.12.8 / Linux 환경에서 기존 115개와 신규 10개, 합계 125개가 0.930초에 모두 통과했다. 신규 10개 별도 실행은 0.008초였다. 실패·오류는 없었고 subTest를 별도 합산하지 않았다. 시간은 테스트 모음의 실행 시간이며 MAC 성능 측정값이 아니다.

기존 7개 테스트 모듈과 patterns.py·compare_mac.py의 검증용 내용은 원격에서 확인한 Git blob SHA와 일치한다. 보완 전 main.py와 README.md도 원격 내용과 대조했다. 검증용 data.json의 LF 정규화 SHA-256은 f1e15a6a4616e76c2c9006e0282374c77eb96921e9f1b6e5b29490da7f235e79이며 값을 변경하지 않았다. 보완 전후 AST 비교로 mac·calculate_score·mac_flat·decide_label·analyze_case·analyze_data·summarize_results의 의미 구조가 유지됨을 확인했다.

원본 JSON은 6개·3 PASS·3 FAIL·동점 3개가 유지됐다. 별도 CLI 실행으로 모드 1의 X 판정 B, 영 배열의 판정 불가, 오류 후 행 재입력, JSON 성능 표·메뉴 복귀·종료를 확인했다. 로그에는 실제 실행 환경과 입력 및 출력을 남겼다. 원래 프로젝트의 보존 CSV와 validation.log를 갱신하지 않았으며 비교 테스트의 CSV는 임시 폴더만 사용했다.

2026-11-17 Windows / PowerShell 5.1에서 같은 출력 보완본을 직접 실행했다. 신규 출력 보완 테스트 10개는 0.010초에, 전체 자동 테스트 125개는 0.875초에 모두 통과했고 실패·오류는 없었다. 이 시간은 테스트 모음 실행 시간이며 MAC 성능값이 아니다. 이번 Windows 기록은 별도 Linux 검증과 구분한다.

JSON 모드에서 기존 6개 케이스의 3 PASS / 3 FAIL, 동점 3개의 실제 점수 차이·epsilon 기준, 나머지 실패 유형 0개를 확인했다. 수동 모드에서는 공백 없는 101 입력에 대한 같은 행 재입력 후 A 점수 1.0, B 점수 5.0, 판정 B를 확인했고, 메뉴 복귀와 정상 종료도 확인했다. Windows 수동 실행에서 별도의 영 배열 동점 입력을 다시 수행한 기록은 아니며, 동점 처리는 자동 테스트와 앞의 Linux 실행 기록으로 구분한다. 이번 콘솔의 성능 시간은 해당 실행의 관찰값이며 기존 측정표를 대체하거나 최적화 효과를 입증하는 값으로 사용하지 않는다. 이 보완본의 플랫폼 재평가는 아직 진행하지 않았다.

보완본의 플랫폼 평가, 실제 GPU·NPU 실행, 1000×1000 성능·메모리 측정은 수행하지 않았다. 모든 Python 버전의 호환성과 외부 링크의 전체 유효성·웹 렌더링까지 확인한 것은 아니다. 강의의 그림 배치나 폰트 재현이 아니라 페이지별 설명·코드·요구사항을 대조했다.
